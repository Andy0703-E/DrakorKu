# DrakorKu

DrakorKu adalah katalog drama dan movie Asia berbasis React. Aplikasi ini mengambil katalog, detail, episode, dan sumber pemutaran dari API eksternal.

## Fitur

- Katalog terbaru, ongoing, pilihan, dan movie dengan pagination
- Pencarian judul drama
- Halaman detail dengan sinopsis, kategori, statistik, dan daftar episode
- Pemutar video dengan pemilihan kualitas, navigasi episode, melanjutkan waktu tonton, berbagi tautan, dan akses unduhan sumber
- Daftar tontonan pribadi yang tersimpan di browser
- Desain responsif untuk mobile dan desktop
- Halaman kosong, gagal memuat, dan 404 yang informatif

## Menjalankan proyek

```bash
npm install
npm run dev
```

Untuk membuat build produksi:

```bash
npm run build
```

## Teknologi

React, Vite, React Router, Axios, Tailwind CSS, dan Lucide.

## Catatan

Data katalog dan sumber tontonan berasal dari layanan pihak ketiga. Proyek ini tidak menyimpan video secara lokal.
